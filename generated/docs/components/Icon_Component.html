Overview

Icon Component

Sizing wrapper. Centres a glyph of "Icon Size" inside a hit area of "Frame Size", so the drawn icon and the tappable target are chosen independently. Use it wherever an icon is interactive: a 16px glyph in a 40px frame still clears the 40px minimum touch target, while a bare 16px icon does not. 29 valid combinations are defined - the ones where the glyph would exceed its frame do not exist. For a purely decorative icon inside text, place the glyph directly and skip this wrapper.

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Child data-ds-part paths follow the shown layer order; variants with different structures require the corresponding markup. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
