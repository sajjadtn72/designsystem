Mentions

ناحیهٔ متن چندخطی که با تایپ @ (افراد) یا # (موضوع‌ها) انتخاب‌گری کنار مکان‌نما باز می‌کند. اشارهٔ درج‌شده یک واحد است: رنگ primary و وزن Medium روی کل بازه‌اش. پنل از Dropdown / Item و _Listbox / Status ساخته شده. Open برای افراد با نام کاربری در سطر دوم، Open Topic برای موضوع با تعداد گزارش، No Results و Loading مثل Auto Complete. Show Count شمارندهٔ کاراکتر. متن مقدار prop نیست تا رنگ اشاره حفظ شود؛ مستقیم override کنید. مستند کامل: specs/mentions.md

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Child data-ds-part paths follow the shown layer order; variants with different structures require the corresponding markup. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
