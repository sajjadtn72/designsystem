Time Picker

پنل انتخاب ساعت و دقیقه — دو ستون اسکرول‌شونده، سربرگی که مقدار انتخاب‌شده را بزرگ نشان می‌دهد، و نوار عمل پایین. معادل TimePicker در AntD. دو حالت نمایش دارد: Modal که روی دسکتاپ به‌صورت پنل شناور زیر فیلد باز می‌شود، و Bottom Sheet که روی موبایل از پایین صفحه بالا می‌آید. هر خانهٔ ساعت یا دقیقه یک نمونهٔ _Time Picker / Cell است با State: Default، Hover، Focus، Selected، Disabled. مستند کامل: specs/time-picker.md

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Child data-ds-part paths follow the shown layer order; variants with different structures require the corresponding markup. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
