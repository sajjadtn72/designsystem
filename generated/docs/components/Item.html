Overview

Item

A single anchor link. Level sets the indent (L1 top-level, L2 nested); Active marks the section currently in view. Active state must be driven by scroll position, and it is a state, not a selection - only one item is Active at a time. Do not rely on colour alone to show it; the indicator bar carries the meaning for anyone who cannot separate the two purples. DUPLICATE: this set exists twice on the page under the same name. Keep one.

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Child data-ds-part paths follow the shown layer order; variants with different structures require the corresponding markup. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
