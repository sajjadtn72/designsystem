Divider

یک خط افقی که دو تکه محتوا را از هم جدا می‌کند. Mode=Normal خط مویی توپر است؛ Mode=Dash خط‌چین، برای گروه‌بندی ضعیف‌تر و موقت (مثلاً «موارد پیشنهادی» زیر «موارد انتخاب‌شده»). جداکننده آخرین ابزار جدا کردن است، نه اولین. فاصله بیشترِ کار جدا کردن را انجام می‌دهد؛ خط فقط وقتی لازم است که فاصلهٔ تنها شکست خورده باشد. مستند کامل: specs/divider.md

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Child data-ds-part paths follow the shown layer order; variants with different structures require the corresponding markup. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.

<div class="divider" data-mode="Dash"><div data-ds-part="0" aria-hidden="true"></div></div>
