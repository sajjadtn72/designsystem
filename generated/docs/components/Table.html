Table

جدول داده: ردیفی از سربرگ‌ها (_Table Header) بالای ستون‌هایی که هرکدام از خانه‌های Table Columns ساخته شده‌اند. برای داده‌ای است که کاربر باید مقایسه، مرتب، فیلتر یا روی چند ردیف با هم عمل کند — فهرست بارنامه‌ها، راننده‌ها، سفارش‌ها. معادل Table در AntD و Data Table در shadcn. جدول در Figma ستون‌محور ساخته شده است: هر Column / … یک سربرگ و خانه‌های زیرش است، و نوع محتوای خانه‌ها (متن، برچسب، سوئیچ، امتیاز، عملیات) با Type در Table Columns تعیین می‌شود. مستند کامل: specs/table.md

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Child data-ds-part paths follow the shown layer order; variants with different structures require the corresponding markup. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
