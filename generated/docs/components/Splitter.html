Splitter

دو ناحیهٔ کنار هم (یا زیر هم) که کاربر با کشیدن نوار بین‌شان، سهم هرکدام را خودش تعیین می‌کند و می‌تواند یکی را کاملاً جمع کند. معادل Splitter در AntD. این کامپوننت در Figma در عمل خودِ نوار مرکب است: یک Splitter / Bar Dragger برای کشیدن و دو Splitter / Collapse Button برای جمع کردن هر طرف. پنل‌ها در آن نیستند — محتوای دو طرف کار صفحه است. مستند کامل: specs/splitter.md

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
