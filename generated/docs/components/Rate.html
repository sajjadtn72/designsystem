Rate

Focus حلقه را دور همان ستاره‌ای می‌کشد که فوکوس صفحه‌کلید روی آن است. Show Value عدد را کنار ستاره‌ها می‌نویسد و باید روشن بماند: ستاره تنها حامل مقدار نیست. Show Count تعداد رأی. مستند کامل: specs/rate.md
