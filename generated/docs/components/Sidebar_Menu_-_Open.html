Sidebar Menu / Open

منوی عمودی ناوبری اصلی برنامه — فهرست بخش‌ها با آیکون و برچسب، که هر بخش می‌تواند زیرمنو داشته باشد. داخل Sidebar می‌نشیند و معادل Menu با mode="inline" در AntD و SidebarMenu در shadcn است. از قطعه‌های جدا ساخته شده: _Product Name & Logo بالای منو، و سیزده _Main که هرکدام یک _Menu Items (آیتم سطح اول) و در صورت نیاز یک _Sub Menu All Types (گروه زیرمنو با ۲ تا ۱۰ آیتم) دارند. مستند کامل: specs/menu.md

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Child data-ds-part paths follow the shown layer order; variants with different structures require the corresponding markup. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
