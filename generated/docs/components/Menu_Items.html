Overview

_Menu Items

A top-level navigation item. Type carries Default, Hover, Selected and Disable; Just Icon collapses it to the icon alone for the rail state. Selected is a destination state - exactly one item is Selected per navigation, and it must survive a page reload. When Just Icon is On the label disappears, so the item needs a tooltip and an accessible name in code, or the rail becomes unusable for screen readers.

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Child data-ds-part paths follow the shown layer order; variants with different structures require the corresponding markup. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
