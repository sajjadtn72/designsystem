Avatar

نشانگر هویت. Type=Image عکس، Initials حروف اول روی primary/container وقتی عکس نیست، Icon وقتی نام هم نیست (کاربر مهمان). Shape=Circle آدم‌ها، Square سازمان و دارایی، با گردی که با اندازه بزرگ می‌شود. Size ۲۴ تا ۵۶؛ پیش‌فرض sm (۳۲). Show Status نقطهٔ آنلاین در پایین-چپ (شروعِ پایین در RTL). مستند کامل: specs/avatar.md

Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
