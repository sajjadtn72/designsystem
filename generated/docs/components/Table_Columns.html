Table Columns

یک خانهٔ جدول با دوازده نوع محتوا. Type تعیین می‌کند داخل خانه چه باشد: Text، Tag، Badge، Action، Switch، Checkbox، Just Checkbox، Dropdown، Rate، Plus، Minus و Slot. جدول از روی هم چیدن همین خانه‌ها ساخته می‌شود؛ هیچ خانه‌ای خارج از این کامپوننت ساخته نشود. State یا Default است یا Hover/Select — روشن شدن ردیف هنگام هاور یا انتخاب. مستند کامل: specs/table-columns.md

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Child data-ds-part paths follow the shown layer order; variants with different structures require the corresponding markup. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
