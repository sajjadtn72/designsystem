Overview

Buttons

دکمه یک فرمان را همان‌جا اجرا می‌کند: ذخیره، ارسال، باز کردن یک پنل، حذف. معادل Button در AntD و shadcn است، با شش Type که سلسله‌مراتب اهمیت را می‌سازند، چهار Size (xl ۵۶ / lg ۴۸ / md ۴۰ / sm ۳۲ پیکسل) و پنج State. Type تزئین نیست، رتبه است: در هر تصمیم فقط یک Primary؛ Tonal عمل دوم کنارش؛ Outline Secondary عمل خنثی (انصراف)؛ Text عمل سوم و درون‌خطی. دو Primary در یک نما یعنی تصمیم هنوز گرفته نشده. مستند کامل: specs/buttons.md

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Child data-ds-part paths follow the shown layer order; variants with different structures require the corresponding markup. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
