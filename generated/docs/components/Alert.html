Overview

Alert

پیامی درون‌خطی که به محتوای مربوط به خودش چسبیده است — بالای فرم، داخل کارت، بالای جدول — و تا وقتی شرایطش برقرار است سر جایش می‌ماند. شناور نیست، خودبه‌خود محو نمی‌شود و جای صفحه را هم نمی‌گیرد. Mode می‌گوید کدام وضعیت: Success، Warning، Info یا Error. Alert به یک مکان تعلق دارد، نه به یک لحظه. اگر کاربر برود و برگردد و مشکل هنوز هست، Alert هم باید هنوز باشد — همین آن را از Message و Notification جدا می‌کند. مستند کامل: specs/alert.md

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Child data-ds-part paths follow the shown layer order; variants with different structures require the corresponding markup. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
