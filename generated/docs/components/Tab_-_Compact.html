Tab / Compact

تب ساده‌شده‌ای که داخل نوار تب زیرخط‌دار (Tab / Line) می‌نشیند: یک برچسب، یک آیکون اختیاری و یک Badge شمارشی. اندازه ندارد و فقط سه حالت دارد. نامش برای جدا شدن از Tab / Item عوض شده که آن هم پیش‌تر «Tab» نام داشت. مثل هر تب، بین نماهای یک context جابه‌جا می‌کند — نه بین صفحه‌ها. به‌تنهایی معنا ندارد؛ همیشه عضوی از یک tablist است. مستند کامل: specs/tab-compact.md
