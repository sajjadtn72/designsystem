Date picker - Years & months

پنل انتخاب سال و ماه — همان جایی که کاربر با ضربه یا کلیک روی عنوان تقویم به آن می‌رود. Panel=Years شبکه‌ای از سال‌ها و Panel=Months دوازده ماه را نشان می‌دهد. برای تاریخ‌های دور، مثل تاریخ تولد، باز کردن مستقیم پنل سال ده‌ها ضربه را حذف می‌کند. دو حالت نمایش دارد: Modal و Bottom Sheet، هم‌تراز با Mobile Date Picker. معادل picker="year" و picker="month" در AntD است. مستند کامل: specs/date-picker-years-months.md

Structure sample: replace div tags with appropriate accessible HTML elements. Keep data attributes to target exact Figma variants and child layers. Child data-ds-part paths follow the shown layer order; variants with different structures require the corresponding markup. Interactive states have pseudo-class selectors and explicit data attributes for previewing. CSS does not implement interaction behavior.
